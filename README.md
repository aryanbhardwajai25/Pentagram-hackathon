🏥 MedFlow
MedFlow is a user-friendly platform designed to streamline hospital/clinic management. It
allows a site owner (admin) to track which patients are being treated under which doctor,
monitor patient status, and keep an eye on ambulance waiting times — all from one place.
---
✨ Features
-󰞯 Doctor–Patient Mapping — View which patients are currently assigned to which doctor.
-📋 Patient Status Tracking — Keep track of each patient's current treatment status.
-🚑 Ambulance Waiting Time — Monitor and display real-time ambulance waiting times.
-🖥 Admin Dashboard — A central view for the site owner to oversee all ongoing activity.
-🎨 User-Friendly Interface — Designed to be simple and intuitive for both staff and admins.
---

🚀 Getting Started
Clone the repository:
```bash
git clone <your-repo-link>
```
Navigate to the project folder:
```bash
cd medflow
```
Open `index.html` in your browser (or run your dev server, if applicable).
