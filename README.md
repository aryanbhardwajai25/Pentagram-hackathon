🏥 MedFlow

MedFlow is a user-friendly hospital/clinic management platform that helps administrators monitor patients, doctors, treatment status, and ambulance waiting times from one centralized dashboard.

✨ Features

👨‍⚕️ Doctor–Patient Mapping — View which patients are assigned to each doctor.

📋 Patient Status Tracking — Monitor the current treatment status of patients.

🚑 Ambulance Waiting Time — Display ambulance waiting times.

🖥️ Admin Dashboard — Centralized view of ongoing hospital activities.

🎨 Simple UI — Clean and intuitive interface for staff and administrators.

❗ Problem

Hospitals manage large amounts of information across patients, doctors, treatments, and emergency services. Without a centralized view, it can be difficult for administrators to quickly understand the current situation.

💡 Solution

MedFlow brings essential hospital information into a single dashboard, allowing administrators to quickly monitor doctor–patient assignments, patient status, and ambulance waiting times.

🛠️ Tech Stack

HTML5 — Application structure

CSS3 — Styling and responsive UI

JavaScript — Interactivity and application logic
